# 当前训练数据的带外恢复

新风基线使用`data/新风转轮基线_9输入/`中的三份UTF-8-SIG CSV：新风转轮_训练集.csv、新风转轮_验证集.csv、新风转轮_测试集.csv。三份共605,379条，分区分别485,041/57,000/63,338，列顺序ID、9个风量输入、六输出。转轮转速从模型输入删除，原17列审计来源仍保留；没有新删行或重划分区。

主转轮继续使用`data/转轮数据集_尺寸隔离_8比1比1/`中的主转轮三份9输入CSV。精确SHA-256、大小和历史文件身份见[身份清单](../docs/handoff/模型与数据身份.json)。新风训练显式指定--profile xf和新目录；不要把只包含新风三份CSV的目录传给--profile all。

各分区按完整厚度×直径组合隔离，scaler只在train拟合；ID、power和露点不入模型。数据和模型均不上传GitHub，其他设备需要带外恢复；仅重新训练不能保证得到相同权重。旧XLS与旧10输入CSV仅用于历史追溯。
