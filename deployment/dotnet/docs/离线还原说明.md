# 离线 NuGet 接入说明

在 Visual Studio 中添加本目录为本地 NuGet 源，安装 Dehumidifier.Simulation 1.0.1；宿主使用 .NET 8、Windows x64。主包及运行依赖均在本目录；完整 SDK 和测试框架不属于离线运行依赖。

主包 targets 将 ONNX 模型及契约复制到宿主输出的 `Dehumidifier/models/`。部署时保留整个输出目录。

## 构建包内独立 WinForms 示例

在包根目录运行以下 PowerShell 命令（需要 Windows .NET 8 SDK）：

```powershell
dotnet restore .\examples\WinFormsDemo\source\WinFormsDemo.csproj --source .\nuget --packages .\build\consumer-packages --force
dotnet build .\examples\WinFormsDemo\source\WinFormsDemo.csproj -c Release --no-restore
```

使用新的缓存目录验证升级过程；示例明确依赖 1.0.1，不会命中旧交付的 1.0.0 主包。示例会复制 `examples/qy1070_case.json` 和 `default_case.json`；运行它不需要源仓库。若要直接试用无需 SDK，打开 `examples/WinFormsDemo/publish/WinFormsDemo.exe`。

业务项目按同样方式使用本地源和独立缓存。NuGet.config 已清除外部源；首次安装 SDK 或重新编译完整测试项目可能需要额外开发依赖。
