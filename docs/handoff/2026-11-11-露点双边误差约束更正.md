# 2026-11-11 露点双边误差约束更正

用户明确：给定目标露点，只允许正负1℃误差。目标−45℃时，合格范围是**−46～−44℃，含边界**，过干和过湿都不合格。

核查发现，上轮新增的optimization.py只用`dp > dew_point_max_degC`排除过湿，漏掉下限；2026-11-10交接文档和README沿用了同一错误解释。已撤销约−92℃旧最优及其10.67%作为当前要求下优化结论的有效性。旧原文和参数按字节保存为历史副本，旧展示文件加注失效；原始搜索JSON、权重、数据和物理源码不动。

当前Python接口改为`dew_point_target_degC`与`dew_point_tolerance_degC=1`，硬性检查绝对误差≤1℃。误差容限不得超过1℃；零湿度的−inf仍是合法前向状态，但不满足有限目标带。新CLI使用`--dew-point-target -45 --dew-point-tolerance 1`，移除语义错误的`--dew-point-max`参数。报告schema_version升级2并记录`absolute_error_to_target`。

50项专项测试通过，覆盖双边界、略微越界、过干、过湿、旧−92℃结果、零湿度、初始候选重新计算及现有接口。

按原入口/流量/尺寸/转速、原控制搜索范围与0.1℃分辨率重跑真实模型。只改变露点约束，不重训、不修复暂缓的主轮覆盖，也不放宽整机收敛或过饱和门禁。旧3990条记录中24条符合正确目标带，最低146.353531kW、露点−45.53516℃；该点仅作为重新计算的起点，旧标签不被直接当作当前验证。
