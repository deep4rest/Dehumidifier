# 交付命名与数据版本规则

用户2026-11-24明确：上一批新风冷吹风量修正后的产物，对外交付版本更正为 **v2.1**。只有实际扩充训练数据时，数据版本加1，例如v2.1→v2.2；同一数据版本的字段修正、重训、代码修复、推理精度调整或重新封装均沿用原版本。同一批扩充数据的多次训练和构建只对应一个数据版本。

基础产物名不含版本：`露点与能耗预测模型`和`最优能耗工况搜索模型`。旧名称中的v2属于版本标记，不是固定产品名的一部分；对外名称只出现一次版本，例如`露点与能耗预测模型_20261124_v2.1.zip`。交付ZIP及其内部顶层目录使用`产物名_YYYYMMDD_v主版本.数据版本`，日期按用户时区的实际交付日。本次重新交付使用`20261124_v2.1`；manifest、ZIP的.sha256旁文件和交付索引配套使用同一名称，不能仅修改ZIP文件名。

打包入口新增必填`--delivery-date YYYYMMDD`和可选`--delivery-version 2.1`；API调用也应显式给出用户时区的交付日期。版本默认2.1，只有扩充训练数据时由本次数据版本决定新值。脚本在创建目录前校验日期与两段版本，并使用完整目录名追加扩展名，避免将v2.1中的`.1`误当文件扩展名截断。
