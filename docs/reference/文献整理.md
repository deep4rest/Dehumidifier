### Data-driven Offline Reinforcement Learning for HVAC-systems.（2022）

论文针对空气源热泵地板供暖，用传统控制器数据训练黑箱环境，再在该环境中预训练多智能体 RL，部署后允许有限在线微调。

主要发现
- LSTM 黑箱模型相对 MLP 的一步预测误差降低 45%；为不同预测步长分别建模又平均改善 19%。HVAC动态中历史记忆和多步模型结构很重要，单步无记忆模型可能不足。
- 历史数据建模 + 模型内预训练 + 有保护的在线微调的技术路线可行性
  
### Experimental evaluation of offline reinforcement learning for HVAC control in buildings（2024）

论文在 MixedUse 和 DataCenter 两个模拟建筑环境中比较 TD3、SAC、TD3+BC、BCQ、CQL，并引入 Transformer 历史编码。

主要发现：

- 高质量但覆盖不足的数据会使普通 TD3/SAC 在纯离线训练中失控，TD3+BC、BCQ、CQL因限制偏离行为数据而稳健得多；其环境中 CQL总体最好。
- 纯专家轨迹未必最好。适量次优轨迹能增加转移多样性，便于离线 RL 拼接改进；噪声过大又会降低质量。
