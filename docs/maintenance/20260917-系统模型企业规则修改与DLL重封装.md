## 一、改动 1：再生混风企业风量规则

规则：Heater_OA 入口流量目标 = 新风转轮处理出口流量 / 3。
R2 再生出与 R1 冷吹出**先完全混合**；可用量 ≥ 目标 → 关闭补风并从混合气流漏掉多余（成分不变，仅减流量）；可用量 < 目标 → 按 `regen_outdoor_air` 补风至目标，补风量以 YAML 配置流量为上限，缺口告警并记录（< 1e-9 kg/s 的浮点缺口视为达标）。KAN 的 `regen_flow` 输入 = 规则执行后的实际入口流量。

实现：`system.py`（simulate 分支逻辑 + `SystemResult.regen_mix_rule` 字段 + `simulate_coupled_xf` 结束后一次性告警）、`config.py`（派生流量 r1_regen = min(目标, 可用量+补风配置)）、`run_records.py`（JSON 序列化）；C# `Simulator.cs`/`Contracts.cs`/`RunRecorder.cs`/`Configuration.cs`/`Program.cs`（verify 输出）同步。

## 二、改动 2：湿空气公式对齐企业参考代码

### 2.1 RH/AH 一致性检查结论（需求 2.1）

| 项目 | 改动前 | 企业参考代码 | 处理 |
|---|---|---|---|
| ≥0℃ 饱和压 | ASHRAE 液态水多项式 | 完全相同（逐系数） | 不变 |
| ≤0℃ 饱和压 | Murphy–Koop 过冷水 | 冰面基准多项式（-10℃ 时约 259 vs 286 Pa） | **已替换**，分界 `T<=0` |
| 水汽比 | 0.621945 | 0.62198 | **已对齐**（差 0.006%） |
| RH | p_v/p_ws，0~1，带压力参数 | 同物理式，百分数，固定 101.325 kPa | 结构一致；接口保持 0~1 与压力参数 |
| “绝对湿度 AH” | 含湿量 W (g/kg) | 参考代码 AH 输出实为含湿量 g/kg（0.62198·p_v/(P−p_v)） | 同一物理量 |
| 风量密度换算 | 0.622 | 未涉及 | 保持 0.622 不变 |

数值核对：新 SVP 与参考代码在 [-75,-40,-20,-1,0,1e-9,20,60]℃ 差值 0.00e+00（逐位一致）；RH↔W 往返在 (35℃,50%)、(-10℃,80%)、(20℃,30%) 与参考代码 AH/RH 互算结果一致。

### 2.2 露点 ↔ 含湿量 DptAH 查表（需求 2.2）

- 表：88 项，`DptAH[i]` = 露点 −i℃ 对应含湿量，覆盖 0~−87℃，101.325 kPa 标定；区间线性插值（露点 −0.5℃ ↔ W=0.5×(3.764+3.466) 双向验证通过）。
- W > 3.764（超出表）：同一饱和压公式数值反演（混合方案；区间 [-150,100]℃，覆盖表上界 3.764 与公式 0℃ 饱和值 3.774 之间的窄缝及低压工况）。
- 0 < W < 0.0001：最后一段斜率线性外推（W=0.00005 → −89.5℃）。
- W = 0：保持 `-inf` 干燥极限；新增 `humidity_ratio_from_dew_point_C` 反向换算（`-inf` → 0）。
- 表第 20 项（露点 −19℃，0.741）与公式值偏离约 6%，疑为原始表笔误，**按规格原样实现**。
